# Продукт: бачення, користувачі, MVP

Що будуємо і для кого. Бачення, цільова аудиторія, проблеми користувачів, Croatia-specific контент, межі MVP, критерії успіху.

## 1. Загальна інформація

**Назва: Croatia survival**

**Призначення:** мобільний AI-додаток для системного вивчення хорватської мови україномовними користувачами.

**Мова інтерфейсу:** українська.

**Цільова мова:** хорватська.

**Цільовий діапазон:** A0 → A1 → A2 → B1 → B2.

**Основна ціль:** привести користувача від повного нуля до самостійного використання хорватської в повсякденному, соціальному та робочому середовищі.

**Команда:**

1 Human Product Owner + AI Agent / AI Agent System

AI виконує ролі:
- Product Analyst
- Business Analyst
- UX/UI Designer
- Learning Designer
- Linguistic Content Designer
- Software Architect
- Mobile Developer
- Backend Developer
- AI Engineer
- Data Engineer
- QA Engineer
- Analytics Engineer
- Technical Writer

Людина відповідає за:
- vision;
- business decisions;
- product priorities;
- фінальне затвердження;
- критичні лінгвістичні/продуктові рішення;
- release approval.

## 2. Product Vision

Створити персонального AI-викладача хорватської мови для україномовної людини, який поєднує:

Structured Curriculum + Spaced Repetition + Retrieval Practice + Comprehensible Input + Extensive Reading + Listening + Speaking

+

Conversation + Contextual Learning + AI Tutoring + Adaptive Learning

Продукт не повинен бути просто набором flashcards.

Основна мета:

**Користувач повинен навчитися робити реальні речі хорватською мовою.**

## 8. Основний Product Loop

REAL LIFE PROBLEM → "What do I say?" → Croatian phrase → Understand → Practice → Speak → Save → SRS

Цей loop є однією з ключових конкурентних переваг продукту.

## 9. Target Users

**Primary**

Україномовний дорослий:
- живе в Хорватії;
- працює в Хорватії;
- переїхав до Хорватії;
- планує переїзд;
- має A0–B1;
- хоче практичну хорватську.

**Secondary**
- туристи;
- студенти;
- члени сімей;
- люди з довгостроковим проживанням;
- remote workers.

## 10. User Problems

Користувач повинен мати можливість вирішити такі проблеми: **Я не знаю, що сказати.**

→ What do I say?

**Я почув фразу, але не зрозумів.**

→ What did I hear?

**Я знаю слово, але не можу його використати.** → Production practice.

**Я постійно забуваю слова.**

→ SRS.

**Я розумію textbook Croatian, але не людей.** → Listening + authentic-ish dialogues + speech variation. **Я боюся говорити.**

→ AI role-play.

**Я знаю граматику, але не використовую її.** → contextual production.

## 90. MVP

MVP should contain:

- A0
- A1
- ~1,500 lexical items
- core grammar
- SRS
- listening
- basic speaking
- AI tutor
- basic role-play
- placement
- progress
- offline lessons
- analytics

The entire 10,000-item B2 curriculum should **not** block MVP.

## 92. User Stories

**US-001**

**As a beginner**, I want to start from zero so that I don't need prior Croatian knowledge. Acceptance:
- A0 option exists;
- first lesson requires no Croatian;
- Ukrainian explanations are available.

**US-002**

**As a learner**, I want the app to remember my mistakes.

Acceptance:
- errors are stored;
- relevant items return to practice;
- repeated errors influence adaptive learning.

**US-003**

**As a learner**, I want to practice speaking.

Acceptance:
- microphone works;
- speech is transcribed;
- AI provides useful correction;
- retry is possible.

**US-004**

**As a learner in Croatia**, I want help with real situations. Acceptance:
- scenario library exists;
- scenario difficulty matches level;
- user can practice dialogue.

## 99. Product Success

The product succeeds if users demonstrate measurable improvement in:

- Vocabulary retention
- Listening comprehension
- Speaking performance
- Reading comprehension
- Writing
- Interaction
- Mediation

The product should not optimize simply for:

- daily opens
- screen time
- XP
- number of clicks
- number of flashcards

## 100. Critical Product Principle

The product must continuously answer:

**What can the user do in Croatian now that they could not do before?** Every major feature should have a measurable answer.

## 110. Final Definition

**Croatia survival** — це AI-native система вивчення хорватської мови для україномовних користувачів, яка проводить користувача від A0 до B2 через приблизно 10 000 high-value lexical concepts, систематичне retrieval + spaced practice, comprehensible input, extensive reading, listening, speaking, writing, interaction та mediation.

Основна мета не:

«вивчити 10 000 слів».

Основна мета:

**сформувати здатність розуміти та використовувати хорватську в реальних ситуаціях.**

10 000 lexical concepts є **інструментом**, а не кінцевим результатом. Кінцевий результат вимірюється через:

UNDERSTAND + RECALL + PRODUCE + INTERACT + MEDIATE + COMMUNICATE

## 111. Golden Rule

Не будувати одразу:

- 10 000 слів
- 500 уроків
- B2

Спочатку побудувати:

ONE WORD → ONE SENTENCE → ONE DIALOGUE → ONE RETRIEVAL → ONE SPEAKING TASK → ONE SRS REVIEW → ONE REAL-LIFE SCENARIO

і довести, що цей цикл реально навчає.

Після цього AI може масштабувати той самий validated learning architecture до:

10,000 lexical concepts + A0 → B2 + thousands of lessons + thousands of exercises
