# Журнал змін ТЗ

> Що змінилося в ТЗ (`docs/*.md`) після рішень власника. Новий рядок — **угорі** таблиці, після кожного рішення, що змінює ТЗ.
> Повна таблиця рішень — `docs/HISTORY.md` → «Прийняті рішення»; тут — лише що саме змінено в ТЗ.
> Ведеться з 2026-11-11; ранішні рішення — лише в `HISTORY.md`.
