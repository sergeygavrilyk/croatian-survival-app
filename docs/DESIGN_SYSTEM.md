## 1. Напрям: Adriatic Utility

Застосунок має бути **спокійним, сучасним, дружнім, практичним і якісним**. Він **не має бути** іграшковим, туристичним, строкатим чи «геймифікованим».

- Без прапора, шахівниці й фото Хорватії на кожному екрані.
- **Adriatic Blue** — дія. **Slate** — фон і текст. **Emerald** — успіх. **Amber** — увага, підказка, «майже». **Rose** — помилка. **Indigo** — усе, що згенерував AI.
- Багато вільного місця, мало декору. Ієрархія будується фоном, рамкою і відступами, а не градієнтами, важкими тінями чи світінням.

Головний принцип:

> **Кожен екран відповідає на питання «Що я можу зробити зараз?»** — і має одну головну дію.

Навчальні принципи, які стають правилами UI:

- **Пригадування важливіше за впізнавання.** Відповідь спершу прихована. Ми питаємо «Як попросити рахунок?», а не показуємо `račun = рахунок`.
- **Говорити і писати важливіше за пасивне читання.**
- **Реальне вміння важливіше за XP.**
- Хорватське слово чи фраза — головний об'єкт на екрані. Український переклад завжди менший і другорядний.

## 3. Токени (Tailwind 4, `app/globals.css`)

Компоненти використовують **семантичні** класи (`bg-primary`, `text-ink-muted`, `rounded-card`), а не сирі (`bg-blue-600`, `text-gray-500`). Тоді тему можна змінити в одному місці.

Цільовий `globals.css` (впроваджує UI-001):

```css
@import "tailwindcss";

/* Шрифти: next/font кладе змінні на <html>, тому inline */
@theme inline {
  --font-sans: var(--font-inter), ui-sans-serif, system-ui, sans-serif;
  --font-heading: var(--font-jakarta), var(--font-inter), ui-sans-serif, sans-serif;
}

@theme {
  /* Поверхні й текст */
  --color-canvas: var(--color-slate-50);        /* фон застосунку */
  --color-surface: var(--color-white);          /* картки, листи */
  --color-surface-muted: var(--color-slate-100);
  --color-line: var(--color-slate-200);         /* рамки, роздільники */
  --color-ink: var(--color-slate-900);          /* основний текст */
  --color-ink-muted: var(--color-slate-600);    /* пояснення, переклад */
  --color-ink-subtle: var(--color-slate-500);   /* метадані (лише ≥ 14 px) */

  /* Дія */
  --color-primary: var(--color-blue-600);
  --color-primary-hover: var(--color-blue-700);
  --color-primary-pressed: var(--color-blue-800);
  --color-primary-soft: var(--color-blue-50);
  --color-primary-ink: var(--color-blue-700);   /* синій текст на білому */

  /* Зворотний зв'язок */
  --color-success: var(--color-emerald-600);
  --color-success-soft: var(--color-emerald-50);
  --color-success-line: var(--color-emerald-200);
  --color-success-ink: var(--color-emerald-700);
  --color-warning: var(--color-amber-500);
  --color-warning-soft: var(--color-amber-50);
  --color-warning-line: var(--color-amber-200);
  --color-warning-ink: var(--color-amber-800);
  --color-danger: var(--color-rose-600);
  --color-danger-soft: var(--color-rose-50);
  --color-danger-line: var(--color-rose-200);
  --color-danger-ink: var(--color-rose-700);

  /* AI */
  --color-ai: var(--color-indigo-600);
  --color-ai-soft: var(--color-indigo-50);
  --color-ai-line: var(--color-indigo-100);
  --color-ai-ink: var(--color-indigo-700);

  /* Форми */
  --radius-control: 0.75rem;  /* кнопки, поля — 12 px */
  --radius-card: 1rem;        /* картки — 16 px */
  --radius-hero: 1.5rem;      /* навчальна картка, нижній лист — 24 px */

  /* Типографіка: розмір / міжрядковий / вага */
  --text-display: 2rem;      --text-display--line-height: 2.5rem;  --text-display--font-weight: 700;
  --text-h1: 1.75rem;        --text-h1--line-height: 2.25rem;      --text-h1--font-weight: 700;
  --text-h2: 1.375rem;       --text-h2--line-height: 1.75rem;      --text-h2--font-weight: 700;
  --text-h3: 1.125rem;       --text-h3--line-height: 1.5rem;       --text-h3--font-weight: 700;
  --text-body-lg: 1.0625rem; --text-body-lg--line-height: 1.625rem;
  --text-body: 1rem;         --text-body--line-height: 1.5rem;
  --text-label: 0.875rem;    --text-label--line-height: 1.25rem;   --text-label--font-weight: 600;
  --text-caption: 0.75rem;   --text-caption--line-height: 1rem;    --text-caption--font-weight: 500;
  --text-word: 2.25rem;      --text-word--line-height: 2.75rem;    --text-word--font-weight: 700;  /* хорватське слово */

  /* Рух */
  --ease-out-soft: cubic-bezier(0.2, 0.8, 0.2, 1);
  --animate-fade-in-up: fade-in-up 220ms var(--ease-out-soft) both;
  --animate-wave: wave 2.5s infinite;

  @keyframes fade-in-up {
    from { opacity: 0; transform: translateY(8px); }
    to   { opacity: 1; transform: translateY(0); }
  }
  @keyframes wave {
    0%, 60%, 100% { transform: rotate(0deg); }
    10%, 30% { transform: rotate(14deg); }
    20% { transform: rotate(-8deg); }
    40% { transform: rotate(-4deg); }
    50% { transform: rotate(10deg); }
  }
}

@layer base {
  html { color-scheme: light; }                       /* темна тема — пізніше, свідомо */
  body { @apply bg-canvas text-ink font-sans antialiased; }
  :focus-visible { @apply outline-2 outline-offset-2 outline-primary; }
}

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

Правила:

- Поза `@layer` у `globals.css` нічого не стилізуємо: такі правила перебивають класи Tailwind (так виникла проблема з Arial).
- `tailwind.config.ts` після UI-001 видаляємо. Тема живе лише в `@theme`.
- Тіні: `shadow-sm` за замовчуванням, `shadow-md` для модалок, нижнього листа і плаваючої кнопки. `shadow-lg` / `xl` / `2xl`, градієнти, `backdrop-blur` і `ring-4` декору не використовуємо.
- Колір **завжди має значення**: синій — дія, зелений — засвоєно, бурштиновий — увага або «майже», рожевий — виправлення, індиго — AI, **колір рівня** — до якого рівня належить урок / модуль (§3.4). Колір як прикраса заборонений.

### 3.4. Кольори рівнів і тематичні іконки (рішення власника 2026-10-20)

Власник: екрани без кольору й іконок виглядають «ніби дементор висмоктав усю радість». Тому:

| Рівень | Назва | Колір (`--color-level-*`) |
|---|---|---|
| A0 | Перші кроки | рожевий (`rose-600`, світлий `rose-50`) |
| A1 | Щоденне життя | індиго (`indigo-600`) |
| A2 | Впевнено в побуті | бірюзовий (`teal-700`) |
| B1 | Самостійно | помаранчевий (`orange-700`) |
| B2 | Вільно | фіолетовий (`purple-600`) |

- Токени: `level-a0` (суцільний, з білим текстом ≥ 4.5:1), `level-a0-soft`, `level-a0-line`, `level-a0-ink` — так само для A1–B2. Класи — лише через `lib/levels.ts` (`levelStyle(level)`: `solid`, `soft`, `ink`, `line`, `bar`), не склеювати назви класів.
- Де колір рівня: `LevelBadge` (усюди), вибрана вкладка рівня, плитка іконки модуля, підпис «МОДУЛЬ A0.1», прогрес модуля, кружечок уроку, картка «Наступний урок». Головна кнопка дії лишається синьою (`primary`).
- **Тематичні емодзі модулів** (`moduleIcon(level, order, title)` у `lib/levels.ts`): 👋 A0.1, 🔢 A0.3, 🍽️ A0.7, 🛒 A0.8, 🆘 A0.10, 🚌 A1.4, 🩺 A1.7… Підсумкові модулі — 🏆. Новий модуль — додати рядок у `MODULE_ICONS`, інакше іконка підбирається за назвою (запасний 📚). Прапори-емодзі не використовуємо (у Windows — літери).
- **Біля слова** («Тренажер», «Словник», 2026-10-20) — `WordTile` (`components/ui/WordTile.tsx`): емодзі модуля, де слово **вперше** трапляється в уроках (`wordThemes()` у `lib/word-theme.ts`: рівень → модуль → блок → урок), на світлому фоні **кольору рівня слова** (`lexemes.cefr`); слово поза уроками — перша літера в кольорі рівня (*Lj*, *Nj*, *Dž* — одна літера). Поруч — `LevelBadge`, частина мови українською, у словнику — «✓ Вчу» (слово вже в повтореннях).
- Фільтр рівня (тренажер, словник, читання) — як вкладки рівня на «Уроках»: вибраний рівень залитий своїм кольором, «Усі» — білий (`SegmentedLinks` — проп `activeClassName`).
- **Емодзі категорій** (2026-10-20): тип тексту в «Читанні» — `textTypeIcon()` (`lib/reading.ts`: ✉️ лист, 💬 чат, 🍽️ меню, 🏷️ вивіски…); категорія типових помилок — `categoryIcon()` (`lib/interference.ts`: 🧩 відмінки, 🎭 оманливі слова…). Плитка — на `soft`-фоні рівня (читання) або `warning-soft` (типові помилки), `danger-soft` — особиста помилка (💬 з рольової гри, 🧩 типова).
- **Кінець сесії** — `SessionDone` (`components/ui/SessionDone.tsx`) у тренажері, «Помилках», «Типових помилках», читанні, «Перевір себе» в ситуації: 🎉 ≥ 80 %, 💪 ≥ 50 %, інакше 🌱 «Крок за кроком!» (`sessionCheer()` у `lib/today.ts`), зелена смужка правильних. На 🎉 — конфеті один раз (`Confetti`). Без «провалу» й червоного.
- **Святковий екран після уроку** (2026-10-20) — той самий `SessionDone`: 🎉 «Урок пройдено!» + конфеті, «З першої спроби», плитки `StatTile` «📚 +N нових слів» (зелена) і «🔥 N днів поспіль» (бурштинова, як на «Сьогодні»), «Тепер ви вмієте:» (цілі уроку). Тексти — `lib/celebration.ts`: радіємо вмінню й регулярності, **без тиску й провини** («не перервіть серію», «втратите» — заборонено, перевіряє тест).
- **«Ситуації»** (2026-10-20): групи за темами (`SITUATION_GROUPS`), знак ситуації на `soft`-фоні кольору першого рівня, бейджі рівнів, «✨ Розмова з AI» в індиго, де є рольова гра. **Онбординг**: 👋 «Dobro došli!» на першому кроці, знаки цілей як у ситуаціях, бейдж рівня біля самооцінки, результат тесту в кольорі рівня з 🎉 і конфеті.
- **Талісман-далматинець** (рішення власника 2026-10-20): три мультяшні далматинці на вибір — **Pjegica** («Плямочка», червона краватка, махає лапою), **Šime** (моряк у тільняшці), **Točka** («Крапка», значок із жетоном). Користувач обирає в онбордингу й профілі (`profiles.mascot`; не обрано → Pjegica). `components/ui/Mascot.tsx`: на «Сьогодні» вітається (`hello`, 72 px) замість 👋, на святковому екрані після уроку — замість 🎉 (`pop`, 128 px); `MascotPicker` — три картки з малюнками. Файли — `public/mascot/*.svg`. Аватар-літера в профілі лишається.
- «Профіль»: аватар-літера в кольорі рівня користувача, іконки плиток (`lucide`), стовпчики активності — зелені (як на «Сьогодні»), слова за рівнями — у кольорі рівня, підбадьорення `weekCheer()`.
- Вхід / новий пароль — `AuthShell`: 👋 махає на `level-a0-soft`, картка `rounded-hero`; помилки Supabase — українською (`authErrorUk()` у `lib/auth.ts`).
- Емодзі в інтерфейсі дозволені для: теми модуля, категорії ситуації, привітання 👋 на «Сьогодні» (махає, `animate-wave`; із «Зменшити рух» — стоїть) і коротких підбадьорень (🎉, 💪, 🌱). Кнопки й дії — і далі `lucide-react`.

## 4. Типографіка

- **Plus Jakarta Sans** (`font-heading`) — H1–H3, велике хорватське слово, текст кнопок, мітки прогресу.
- **Inter** (`font-sans`, за замовчуванням) — основний текст, переклади, пояснення, діалоги, читання.

| Клас | Розмір / рядок / вага | Для чого |
|---|---|---|
| `text-display` | 32 / 40 / 700 | привітання на «Сьогодні» |
| `text-h1` | 28 / 36 / 700 | заголовок екрана |
| `text-h2` | 22 / 28 / 700 | секція |
| `text-h3` | 18 / 24 / 700 | заголовок картки |
| `text-word` | 36 / 44 / 700 | хорватське слово або фраза в навчальній картці |
| `text-body-lg` | 17 / 26 | репліки діалогу, читання |
| `text-body` | 16 / 24 | основний текст |
| `text-label` | 14 / 20 / 600 | кнопки, мітки, вкладки |
| `text-caption` | 12 / 16 / 500 | метадані, підписи нижньої навігації |

- **Мінімальний розмір — 12 px.** `text-[10px]` і `text-[9px]` заборонені.
- Поля вводу — не менше 16 px. На iOS менший шрифт змушує браузер збільшувати сторінку під час введення.
- Хорватський текст завжди обгорнутий у `<Hr>` (`lang="hr"`), див. розділ 8.
- Великими літерами з розрядкою (`uppercase tracking-widest`) — лише короткі мітки до 3 слів, не речення.

## 5. Форми, відступи, сітка

| Елемент | Радіус |
|---|---|
| Кнопка, поле, select | `rounded-control` (12) |
| Картка | `rounded-card` (16) |
| Навчальна картка (hero), нижній лист | `rounded-hero` (24), лист — `rounded-t-hero` |
| Бейдж, чип, аватар | `rounded-full` |

`rounded-[2rem]` і «все в `rounded-3xl`» не використовуємо: через це інтерфейс виглядає дитячим.

- Шкала відступів: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64 (класи Tailwind 1–16).
- Бокові відступи: мобільний `px-5` (20), щільні екрани — `px-4`, планшет — `px-6`.
- Ширина вмісту: застосунок — `max-w-6xl mx-auto`, урок, читання і вправи — `max-w-2xl`.
- Стандартна картка: `bg-surface border border-line rounded-card shadow-sm p-5`.

## 6. Рух

| Що | Тривалість |
|---|---|
| Мікровзаємодія (hover, натиск) | 150 ms, `ease-out` |
| Поява екрана, результату | 200–250 ms (`animate-fade-in-up`) |
| Модалка, нижній лист | 250–300 ms |
| Смуга прогресу | 200–300 ms |
| Натиск кнопки | `active:scale-[0.98]` (не `scale-95` / `scale-90`) |

- `animate-fade-in-up` — для появи сторінки, результату, нового зворотного зв'язку чи секції уроку. **Не** для кожного питання, слова, кнопки чи елемента списку.
- `framer-motion` лишається для жестів (свайп карток) і переходів. Обгорнути застосунок у `<MotionConfig reducedMotion="user">`, щоб він поважав системне налаштування «Зменшити рух».
- Без конфеті після кожної правильної відповіді. Конфеті (`components/ui/Confetti.tsx`, `animate-confetti`) — лише раз у кінці уроку / сесії на 🎉 і на результаті тесту рівня; ~2–3 с, `pointer-events-none`, `aria-hidden`, із «Зменшити рух» не показується. Число на плитці підсумку — `animate-pop` (420 ms).

### 7.1 Структура (рішення власника 2026-10-12)

|---|---|---|---|
| **Сьогодні** | `/` | одна головна дія «Продовжити», повторення на сьогодні, «Що сказати?» | ✅ `app/page.tsx` + `components/TodayView.tsx` (2026-10-20) |
| **Уроки** | `/lessons` | рівні → модулі → уроки | `app/lessons` |

| **Ситуації** | `/situations` | ситуації з `phrases` і `conversations` → фрази, діалоги, пізніше рольова гра | ✅ `app/situations`, `app/situations/[code]` (2026-10-12) |
| **Профіль** | `/profile` | прогрес, налаштування, вихід | `app/profile` |

Окремої кнопки «AI-тьютор» у навігації немає. AI вбудовано в процес: «Що сказати?» на «Сьогодні», «Пояснити» в уроці, рольова гра в «Ситуаціях».

### 7.2 Правила

- **Застосунок завжди має власну навігацію.** У режимі standalone PWA кнопки «Назад» браузера немає. Системний жест «назад» — лише запасний варіант.
- Нижня панель (`components/ui/BottomNav`) — **один компонент** у спільному layout для п'яти вкладок, а не копія в кожній сторінці.
  - Іконка й підпис (`text-caption`).
  - Активна вкладка виділена кольором **і** жирністю, бо самого кольору недостатньо.
  - Зона натиску не менша за 44 × 44.
  - Враховує safe-area: `pb-[calc(0.75rem+env(safe-area-inset-bottom))]`, а у viewport — `viewportFit: "cover"`.
  - Посилання — через `<Link>`, а не `router.push`, щоб працювали попереднє завантаження і доступність.
- **Повноекранні заняття** (урок, сесія тренажера, діалог, рольова гра) ховають нижню панель. Угорі — `←`, назва і смуга прогресу.
- Назад і закрити:
  - Сторінка в ієрархії → `← Назад`.
  - Модалка чи лист → `× Закрити`.
  - Урок чи вправа → `←`, прогрес зберігається автоматично.
  - Вихід із незавершеної розмови чи рольової гри → діалог «Завершити заняття? Ваш прогрес буде збережено.» з кнопками [Продовжити] і [Вийти].
- Адмінка (`/admin`) має свій layout і в нижню панель не потрапляє.

- **Лише `PUBLISHED`.** Будь-який запит контенту (`lexemes`, `phrases`, `conversations`, уроки) фільтрує `status = 'PUBLISHED'`.
- **Текст від AI** завжди в `AiPanel` з міткою. Ніколи не змішувати його з перевіреним контентом.
- **Порожньо:** пояснюємо, що буде, і даємо одну дію. Наприклад: «Ще немає повторень. Коли з'являться слова, які час повторити, ми покажемо їх тут. [Вивчити нове]».
- **Завантаження:** `Skeleton` за формою вмісту. Для AI — коротке «Думаю…» з крапками.
- **Помилка:** «Не вдалося завантажити. Ваш прогрес збережено. [Спробувати ще раз]». Для збою аналітики користувачу нічого не показуємо.
- **Офлайн (§76):** уроки, словник, вправи, повторення працюють. Кнопки AI і мовлення вимкнені з поясненням, а не зламані.
- **Аналітика:** новий екран надсилає події з §71 через `track()` / `trackEvent()` (`docs/ANALYTICS.md`). Нові типи подій — PROPOSE.

## 12. Доступність (§98, WCAG 2.2 AA)

- [ ] Масштабування не блокуємо: у `viewport` немає `maximumScale` і `userScalable: false`.
- [ ] Контраст: звичайний текст ≥ 4.5 : 1, великий ≥ 3 : 1.
  - Для тексту використовуємо `-700` / `-800` відтінки (`*-ink`) і `slate-600+`.
  - `text-*-300` / `-400` для тексту не використовуємо.
  - `ink-subtle` (slate-500) — лише для тексту ≥ 14 px.
- [ ] Зона натиску ≥ 44 × 44, основна кнопка ≥ 48 px заввишки.
- [ ] `lang="hr"` на всьому хорватському тексті (`<Hr>`), `lang="uk"` на `<html>`.
- [ ] Кнопки-іконки мають `aria-label`. Смуги прогресу мають `role="progressbar"` і значення.
- [ ] Видимий фокус (`:focus-visible`) і робота з клавіатури.
- [ ] Стан не передається лише кольором: є іконка і текст (✓ △ ✕).
- [ ] `prefers-reduced-motion` враховано в CSS і `MotionConfig`.
- [ ] До кожного аудіо є текст (транскрипт), бо репліка завжди видима або розкривається.
- [ ] Текст збільшується до 200 % без втрати вмісту: жодних фіксованих висот у текстових блоках.

## 13. Адаптивність

- **Мобільний** — одна колонка, основний сценарій.

## 15. Що змінено відносно вихідного документа

- **Стек:** правила переписано під Tailwind 4 (`@theme` у CSS). Вихідний документ спирався на `tailwind.config.ts`, який у проєкті не діє.
- **Стан коду:** документ вважав, що Inter / Plus Jakarta, `bg-slate-50` і `animate-fade-in-up` уже працюють. Насправді шрифти й фон перебиває `globals.css`, а анімації немає (розділ 2).
- **Додано знахідки аудиту:**
  - випадкова темна тема;
  - змішування `gray` і `slate`;
  - 10 px текст;
  - дубльована навігація;
  - «Не знаю» червоного кольору;
  - відсутність `lang="hr"`.
- **Навігація:** TODAY / LEARN / PRACTICE / REAL LIFE / PROFILE стали «Сьогодні / Уроки / Практика / Ситуації / Профіль» і прив'язані до реальних маршрутів. Словник перенесено в «Практику». Структура чекає на «ок» власника.
- **Real Life:** замість абстрактного списку (Café, Bank, Emergency…) — реальні значення `situation` з БД з кількістю контенту.
- **Зворотний зв'язок:** замість двох станів (правильно / неправильно) — 4 вердикти `lib/answer.ts` (точно / діакритика / одруківка / помилка).
- **Прогрес і щоденна ціль:** позначено, які дані вже є, а для чого потрібні міграції.
- **Speaking, What did I hear, Reading:** лишились орієнтиром із прив'язкою до VS-003 / VS-006.
