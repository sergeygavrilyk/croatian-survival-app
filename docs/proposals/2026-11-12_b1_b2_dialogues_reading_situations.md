## 4. Категорії лексики (рішення 4 → міграція M24)

Ваші 7 категорій — і як вони лягають у словник (`lexemes`). Частина полів уже є, але без перевірки значень і ніде не показується.

| Категорія з документа | Поле | Значення |
|---|---|---|
| *Standardni hrvatski* | `register` порожній | стандартна нейтральна (за замовчуванням) |
| *Razgovorni hrvatski* | `register` | `colloquial` (*kužim, nema frke*) |
| *Sleng / žargon* | `register` | `slang`, `jargon` (*fora, ekipa*; офісний, студентський) |
| *Regionalizmi* | `register` + `regionality` | `regional` + регіон: `Zagreb`, `Zagorje`, `Dalmatia`, `Istria`, `Kvarner`, `Slavonia`, `Dubrovnik`, `Lika` |
| *Dijalektizmi* | `register` + `forms.dialect` | `dialectal` + наріччя: `čakavian`, `kajkavian`, `štokavian` |
| *Anglizmi* | **нове** `origin` | `english` (та `italian`, `german`, `turkish`…). Окреме поле, бо англіцизм буває й стандартним (*menadžer*), і розмовним (*lajkati*) |
| *Frazeologizmi* | `vocabulary_type` | **нове значення** `idiom` (*pasti s neba*); `formulaic` лишається для готових формул (*nema problema, vidimo se*) |
| Стандартний відповідник | **нове** `standard_equivalent` | *kužim → razumijem* |
| Вживати чи впізнавати | **нове** `productive` (так / ні) | ні = лише впізнавати: у повтореннях «хорватське → українське», не в «напишіть / скажіть» |
| Дата перевірки актуальності | **нове** `verified_at` | сленг — переглядати раз на рік |
| `vulgar` | `register` | лише B2, лише впізнавати, без SRS — **HUMAN** (план «Živi hrvatski» §9, п. 7) |

**Як це побачить учень** (PR M24, skill `feature-slice-croatia`):

- позначка на картці слова, у списку слів уроку й у словничку тексту: «розмовне», «сленг», «регіонально · Далмація», «наріччя · кайкавське», «англіцизм», «фразеологізм» + «стандартно: *razumijem*»;
- **фільтр «Категорія» в «Словнику»** (стандартні / розмовні / регіональні / фразеологізми);
- `productive = ні` — такі слова не потрапляють у вправи на письмо й говоріння і в тренажер «Написати» (`lib/`, unit-тест);
- наявні 13 позначок (*bura, jugo, fjaka…, ae, onak*) переходять у нові значення без змін змісту.

M24 — адитивна ідемпотентна міграція (нові колонки, CHECK на значення, нове значення `idiom`), без нових таблиць; SQL-тест; DESIGN_SYSTEM — новий бейдж стилю. Після мержу і Approve — пакет позначок для наявних слів A0–A2 (`content-sql-pack`).
