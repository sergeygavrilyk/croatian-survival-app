## Чинні рішення власника (коротко)

Повна таблиця з датами — `docs/HISTORY.md` → «Прийняті рішення».

- **Стек:** Next.js + Supabase + PWA; головна таблиця словника — `lexemes`; схема — лише міграціями; адміни — `app_admins` / `is_admin()`.
- **Контент:** A0 і A1 — бета (PUBLISHED одразу, носій перевіряє після); тексти для читання A2 — теж бета (2026-10-20); решта A2+ — DRAFT до рішення власника. Зміни опублікованого — через `content_versions`, видалення — лише DEPRECATED.
- **Уроки за темою (2026-10-15):** слова уроку — за темою, 20–25 слів і виразів (крім «Числа від 0 до 10»), діалоги під тему, бета. Етапами за планом нижче. Skill: `lesson-topic-rebuild`.
- **Імена в діалогах:** частіше Даша (*Daša*, кличний *Dašo*) / Дар'я (*Darja*).
- **Авторські тексти:** тексти пісень, віршів, книжок не копіюємо (крім суспільного надбання) — лише назва, опис, слова, посилання.
- **Перевірки рівня (§60):** тест не блокує уроки; пройдено = ≥ 70 % загалом і ≥ 50 % у кожній навичці; говоріння можна пропустити.
- **Тренажер:** лише вивчені слова (з пройдених уроків і додані самостійно).
- **AI:** через `AIProvider`, основна модель `gemini-3.6-flash` + запасні (`lib/ai-fallback.ts`); «Мені потрібно сказати…»: спершу перевірені фрази, потім збережений переклад, лише потім AI; щомісячна перевірка моделей — запланована задача.
- **Мовлення:** розпізнавання — Web Speech API (hr-HR) через `SpeechProvider`; офіційне озвучення (Google Cloud / Azure TTS) — ідея на потім (2026-10-15).
- **Талісман (2026-10-20):** три мультяшні далматинці — *Pjegica*, *Šime*, *Točka*; користувач обирає одного (`profiles.mascot`, M18; не обрано → Pjegica). Реалістичний варіант (далматинка / далматинець) власник переглянув і відхилив.
- **Навігація:** «Сьогодні · Уроки · Практика · Ситуації · Профіль»; іконки — `lucide-react`; дизайн — `docs/DESIGN_SYSTEM.md`.
- **Більше радості в дизайні (2026-10-20, власнику подобається — так переробляємо й інші сторінки):** кожен рівень A0–B2 — свій колір, кожен модуль — тематичний емодзі, на «Сьогодні» махає 👋 (`lib/levels.ts`, DESIGN_SYSTEM §3.4).
- **Git:** коміт і push — лише на прохання власника; push робить власник.

## Технічний борг і ризики

- **Запуск для інших людей** — список у `docs/SCALING.md`: AI для ЄС, власний SMTP, видалення акаунта, політика конфіденційності й згода на AI, резервні копії, регіон Vercel, ліміт на переклад, офіційний TTS.
- **Перевірки:** немає E2E (Playwright — PROPOSE), lint / typecheck не в CI; збірку (`npm run build`) запускає власник.
- **Код:**
  - сторінки уроку й тексту — client components з власним запитом і кешем (§75); `getLessonData` дублює логіку; `chat.ts` / `lesson.ts` мають власну копію серверного клієнта;
  - кеш уроків оновлюється ручною зміною версії (`LESSON_CACHE_VERSION`, `CURRICULUM_CACHE_VERSION`) — автоматизувати;
  - `RoleplaySimulator` — старий стиль і прямий `SpeechRecognition`; `LessonView.tsx` не використовується;
  - UI-003: радісний стиль ще не на адмінці, рольовій грі (`RoleplayChat`), етапах уроку до підсумку (`LessonPlayer`) і перевірках рівня (решта — ✅ 2026-10-20);
  - у «Словнику» немає кнопки «Додати в повторення» (слова додаються з уроків і з читання) — запропонувати власнику;
  - новий пароль — мінімум 10 (`MIN_PASSWORD_LENGTH` у `lib/auth.ts`); якщо в Supabase Auth інше значення — змінити там одне число;
  - «Ситуації» / «Говоріння» — перемішування Math.random під час рендеру (ще без помилки #418, бо порядок не в першому рендері).
- **Контент:**
  - уроки A1 — слова частково не за темою (план вище); *vrt, dvorište, selo, učitelj* після A0.5–A0.6 більше не в уроках (повернути в A1);
  - перевірки рівня: у `a0-final` один хибний варіант повторюється у двох завданнях (*Dosta je. Hvala ti!*, #11 і #12) — межа даних генератора;
  - у `lexemes` неповні або хибні частина мови, рід і вид (*čuvati* — «noun», числівники — «noun»); прикладів лише в ~1/3 слів; `normalized` з діакритикою (*domaćin, koža, krađa, nesreća, noćenje, pečat*, *hitna pomod*);
  - читання: у частині текстів 77–85 % знайомих слів (краще 90 %+); тексти B1 — наступний пакет;
  - перевірки рівня: «Складіть» приймає один порядок слів; відповіді видно через API; `skill_progress` не заповнюється;
  - типові помилки: вимова — підказки кирилицею; мало помилок «артиклі» і «вид дієслова».
- **Озвучення** — неофіційний Google Translate TTS (паузи в довгих текстах).
- **Репозиторій:** великі файли даних у корені (`megahr.xlsx`, `insert_all_megahr.sql`, CSV) — перенести; PWA-файли (`public/sw.js`, `public/workbox-*.js`) — у `.gitignore`.
- **Безпека:** захист від злитих паролів — лише тариф Pro (прийнятий ризик; мін. довжина пароля ≥ 10).
