- Авторизація через Supabase; захист маршрутів у `proxy.ts` (у Next 16 це замість `middleware.ts`).
- Екрани: головна (`app/page.tsx`), список уроків (`app/lessons`), урок (`app/(main)/lesson/[id]`), тренажер карток (`app/trainer`), словник (`app/dictionary`), профіль, адмінка (`app/admin`).
- Server actions (`app/actions/`): `lesson.ts`, `srs.ts`, `chat.ts`, `translate.ts` (Gemini), `vocabulary.ts`, `progress.ts`.
- Компоненти: `LessonView.tsx`, `FlashcardTrainer.tsx`, `features/RoleplaySimulator.tsx`.
- TTS: `app/api/tts/route.ts` і Supabase Edge Function `supabase/functions/generate-audio`.
- Python-скрипти для наповнення бази: `generate_sql.py`, `generate_exercises.py`, `generate_audio_google.py`, `seed_1000.py`.
