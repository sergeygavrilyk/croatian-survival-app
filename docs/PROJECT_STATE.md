## Чинні рішення власника (коротко)

Повна таблиця з датами — `docs/HISTORY.md` → «Прийняті рішення».

- **Стек:** Next.js + Supabase + PWA; головна таблиця словника — `lexemes`; схема — лише міграціями; адміни — `app_admins` / `is_admin()`.
- **Контент:** A0 і A1 — бета (PUBLISHED одразу, носій перевіряє після); тексти для читання A2 — теж бета (2026-10-20); решта A2+ — DRAFT до рішення власника. Зміни опублікованого — через `content_versions`, видалення — лише DEPRECATED.
- **Уроки за темою (2026-10-15):** слова уроку — за темою, 20–25 слів і виразів (крім «Числа від 0 до 10»), діалоги під тему, бета. Етапами за планом нижче. Skill: `lesson-topic-rebuild`.
- **Уроки A1 і вище (2026-10-21):** теми можуть повторювати A0, але 90–95 % слів уроку — нові; **до 25 слів — скільки треба для теми**, без добирання (замінює «20–25» для A1+); модулів може бути > 10 (за CEFR і програмами шкіл / університетів); граматика може повторюватись як нагадування; урок «Далмація: Задар» — одразу після «Краї Хорватії». Аудит рівня — skill `level-audit-croatia`.
- **Імена в діалогах:** частіше Даша (*Daša*, кличний *Dašo*) / Дар'я (*Darja*).
- **Авторські тексти:** тексти пісень, віршів, книжок не копіюємо (крім суспільного надбання) — лише назва, опис, слова, посилання.
- **Граматика рівня (2026-10-27):** варіант А — розділ «Граматика рівня» в «Уроках» (теми за модулями, пошук, тема з вправами) + «Підсумок граматики» перед фінальною перевіркою (з варіанта Б), для всіх рівнів; DESIGN_SYSTEM §7.3.
- **Перевірки рівня (§60):** тест не блокує уроки; пройдено = ≥ 70 % загалом і ≥ 50 % у кожній навичці; говоріння можна пропустити.
- **Тренажер:** лише вивчені слова (з пройдених уроків і додані самостійно).
- **AI:** через `AIProvider`, основна модель `gemini-3.6-flash` + запасні (`lib/ai-fallback.ts`); «Мені потрібно сказати…»: спершу перевірені фрази, потім збережений переклад, лише потім AI; щомісячна перевірка моделей — запланована задача.
- **Мовлення:** розпізнавання — Web Speech API (hr-HR) через `SpeechProvider`; офіційне озвучення (Google Cloud / Azure TTS) — ідея на потім (2026-10-15).
- **Талісман (2026-10-20):** три мультяшні далматинці — *Pjegica*, *Šime*, *Točka*; користувач обирає одного (`profiles.mascot`, M18; не обрано → Pjegica). Реалістичний варіант (далматинка / далматинець) власник переглянув і відхилив.
- **Навігація:** «Сьогодні · Уроки · Практика · Ситуації · Профіль»; іконки — `lucide-react`; дизайн — `docs/DESIGN_SYSTEM.md`.
- **Більше радості в дизайні (2026-10-20, власнику подобається — так переробляємо й інші сторінки):** кожен рівень A0–B2 — свій колір, кожен модуль — тематичний емодзі, на «Сьогодні» махає 👋 (`lib/levels.ts`, DESIGN_SYSTEM §3.4).
- **Git:** коміт і push — лише на прохання власника; push робить власник.
