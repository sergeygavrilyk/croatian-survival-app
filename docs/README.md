## Пріоритет при суперечностях

1. Рішення власника продукту: `PROJECT_STATE.md` → «Чинні рішення власника» (повна таблиця — `HISTORY.md` → «Прийняті рішення»).
2. `DATABASE.md`, розділи 112–132 (Addendum v2) — для всього, що стосується бази даних.
3. Решта ТЗ.
4. Поточний код — це реалізація, а не специфікація (§112).

## Куди дивитися під задачу

- Нова фіча або екран → `PRODUCT_SPEC.md` + `ROADMAP.md` (який вертикальний зріз) + профільний файл + `DESIGN_SYSTEM.md` (UI).
- Вигляд, компоненти, навігація, доступність → `DESIGN_SYSTEM.md`.
- Урок, вправи, SRS → `CURRICULUM.md`, `LEARNING_ENGINE.md`.
- Говоріння, AI-тьютор, «What Do I Say?» → `SKILLS_SPEC.md`, `ARCHITECTURE.md` §78–79.
- Таблиці, міграції, RLS → `DATABASE.md`.
- Генерація словника або контенту → `LEARNING_SPEC.md` §13–19, `CONTENT_PIPELINE.md`.
- Як працювати агенту → `AI_RULES.md`.
- Витрати, ліміти, новий AI-провайдер, запуск для інших людей, App Store → `SCALING.md`.
